## Context

The project has undergone significant restructuring to meet Content Security Policy (CSP) compliance, specifically by removing 'unsafe-eval' from configurations. This change is driven by security requirements and a shift towards using Alpine's CSP build. Additionally, the restructuring includes the reorganization of directories and updates to the project's deployment and CI/CD configurations.

## Decision

Adopted Alpine's CSP-compliant build, replacing the standard build and restructuring the directory to enhance security measures. Updated several configuration files and documentation to align with new security practices and improve deployment processes. Integrated Tailscale for secure networking, enhanced telemetry with OpenTelemetry, and improved deployment automation using GitHub Actions and Docker.

## Consequences

The project now benefits from improved security posture due to CSP compliance and structured security practices. However, developers must adjust to the new directory structure and security configurations. The use of Alpine's CSP build may limit some dynamic content features, requiring further adaptation for dynamic behaviors. Deployment processes are more robust, but require familiarity with new tools and configurations.
